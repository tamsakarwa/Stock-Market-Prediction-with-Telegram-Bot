# 📈 Stock Market Prediction with Telegram Bot

## 📌 Project Overview  
This project delivers a **Telegram bot** that predicts stock market prices using various **machine learning models**. Users get real-time forecasts via Telegram, making it a convenient tool for investment decisions—right in your chat.

## 🚀 Key Features  
- Uses ML models like **RandomForest, XGBRegressor, SVR,** and **GradientBoostingRegressor** for prediction.  
- Fetches live stock data, quarterly financials, balance sheets, and cash flows using **yfinance**.  
- Interactive Telegram interface with support for commands like `/start`, `/stop`, and ticker inputs.  
- Scalable for multiple stock symbols and tailored predictions.

## ⚙️ How It Works  
1. **Data Collection**  
   Uses `yfinance` to pull historical price data, financials, and cash flows.

2. **Model Training**  
   Trains ML models (RandomForest, SVR, XGB, Gradient Boosting) using historical data features.

3. **Telegram Bot**  
   - Commands:
     - `/start` – Initialize interaction  
     - `/stop` – End session  
     - `<TICKER>` – Enter a stock ticker to receive predictions  
   - Bot returns next-step (or multi-step) price forecasts generated by trained models.

## 💻 Usage Instructions  

1. **Clone the repository**  
   ```bash
   git clone https://github.com/tamsakarwa/Stock-Market-Prediction-with-Telegram-Bot.git
   cd Stock-Market-Prediction-with-Telegram-Bot
   ```

2. **Create a Telegram bot** using BotFather, retrieve the token, and save it in a `.env` file:
   ```env
   TELEGRAM_BOT_TOKEN=your_bot_token_here
   ```

3. **Install dependencies**  
   ```bash
   pip install -r requirements.txt
   ```

4. **Train the models** (if separate training is used):  
   ```bash
   python src/train_models.py
   ```

5. **Run the Telegram bot**  
   ```bash
   python src/telegram_bot.py
   ```

6. **Interact** with your bot on Telegram and get stock price predictions for any supported ticker.
